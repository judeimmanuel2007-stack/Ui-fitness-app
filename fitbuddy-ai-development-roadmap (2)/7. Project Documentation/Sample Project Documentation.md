# Sample Project Documentation

## Project Name
FitBuddy — AI Fitness Plan Generator

## Project Objective
To build a full-stack AI-powered web application that generates personalized 7-day workout plans, gives nutrition guidance, stores user data, and revises plans based on feedback.

## Technologies Used
- Next.js
- React
- TypeScript
- PostgreSQL
- Drizzle ORM
- Tailwind CSS
- Google Gemini API

## Key Features
- athlete intake form
- 7-day workout generation
- nutrition tip generation
- feedback-based plan updates
- admin panel for all users
- local fallback engine if Gemini is unavailable

## Outcome
The final system is a working AI fitness planner that is deployable, testable, and aligned with the provided AI/ML project workflow.
