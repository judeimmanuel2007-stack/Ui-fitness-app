# 8. Project Demonstration

## Demo Flow
1. Open the homepage.
2. Enter athlete details.
3. Generate a plan.
4. Show the plan page with 7-day structure.
5. Highlight the nutrition tip.
6. Submit feedback.
7. Show the revised plan and revision history.
8. Open the admin dashboard.
9. Demonstrate delete functionality.
