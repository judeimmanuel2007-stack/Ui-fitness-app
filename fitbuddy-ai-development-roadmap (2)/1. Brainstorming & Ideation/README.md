# 1. Brainstorming & Ideation

## Project Title
**FitBuddy — AI Fitness Plan Generator**

## Problem Statement
Many users want personalized workout guidance, but generic online routines do not adapt to their age, weight, goal, intensity, or feedback. Most free workout tools also separate training advice from nutrition support.

## Idea Summary
FitBuddy solves this by using generative AI to:
- generate a structured **7-day workout plan**
- provide a concise **nutrition / recovery tip**
- **update the plan** based on user feedback
- store athlete history for later retrieval and admin review

## Why this idea was selected
- clear real-world use case
- strong fit for Generative AI
- easy to demonstrate end-to-end
- supports iterative personalization
- combines frontend, backend, AI, and database skills in one project

## Target Users
- beginners who need a starting plan
- gym users who want goal-based weekly programming
- students building AI-powered health-tech apps
- coaches/admins who want to review multiple user plans

## Core Value Proposition
"Train. Eat. Adapt." — a simple AI workflow where the system acts like a digital coach and improves the plan over time.
